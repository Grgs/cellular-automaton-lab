## Unreleased

- Polished the comparison wall's labelling and status: a floating caption now names the running comparison (seed · rule · N tilings) so the wall is never an unlabelled animation; the bottom status tracks the shared clock — it no longer sits on "press play" while the demo autoplays — and defers the generation counter to the transport instead of restating a differently framed count. In the Lab, the drawer toggle is now **Show/Hide Controls** rather than "Show/Hide Inspector" (which collides with the wall's board inspector), the focused-board panel's accessible name follows its visible heading instead of a fixed "How the comparison works", and an empty Lab board no longer writes a share blob into the URL — a fresh `#/lab` stays `#/lab`, and erasing a loaded board back to empty drops the slot again.
- Hardened comparison-wall setup and execution: dense periodic tilings such as Snub Trihexagonal now scale to a per-board cell budget instead of exceeding preview limits; every add path enforces a visible adaptive capacity (six boards on capable/wide devices, four on narrow or low-compute devices) before a request is sent; pending reruns say **Apply changes**; WireWorld rule changes are covered through the rendered filmstrip; and wall rule pickers now show only topology-universal rules rather than tiling-specific entries that cannot support a multi-family comparison.
- Added the 2-uniform #3 square-triangle tiling `[4^4; 3^3.4^2]`, with its canonical periodic construction, picker preview, dead-cell palette, reference fixtures, and geometry verification. Editing and running this larger mixed tiling also exposed two Lab lifecycle bugs that are now fixed across all tilings: start/resume returns its running snapshot atomically so a fast simulation cannot starve the UI transition, and internal editor/inspector layout changes no longer rebuild the topology as though the browser window had been resized.
- New aperiodic family: **`socolar-hexagonal`** ("Socolar (hexagon-square-rhomb)") -- the *canonical* Socolar tiling (Socolar 1989) with prototiles {regular hexagon, square, 30° rhomb}, joining the existing `socolar-12-fold` rhombus variant. Implemented as Socolar's cut-and-project construction: exact `Q(sqrt(3))` acceptance windows for 13 tile classes in the `Z[zeta12]` module, extracted from the Tilings Encyclopedia's published patch and verified in exact arithmetic -- regenerating the patch region reproduces the encyclopedia patch tile-for-tile (1876/1876 deep-interior tiles), and a vendored 338-tile literature sample is re-diffed bidirectionally by the family's unit tests. The tiling's Conway-worm phases make an undecorated substitution rule table non-deterministic (the hexagon supertile's boundary "pillows" flip with worm phases), which is why the projection construction is used; full provenance in `docs/contracts/socolar-hexagonal-generator/README.md`. Ships in the Experimental picker group pending visual review.
- Live forks are now full editors: their chip carries **brush sizes (1–3)** and **per-paint undo/redo** (↶/↷). Undo is cell-level — it restores exactly the cells a paint overwrote, to their pre-paint values, even after the simulation has stepped, rather than rewinding the whole board — and a reseed clears the history. Built on the pane's existing per-cell commit diffs, so the shared single-pane editor gains the same undo/redo for free.
- The wall's boards are now **named, searchable, and editable in place**: each board carries its friendly catalog label ("Penrose P3 Rhombs", not `penrose-p3-rhombs`) in its hover chrome, aria strings, and fork chip — the filmstrip payload now sends the label so the client never re-derives it; a new dock **⊞** button (and a trailing **+ Add tiling** ghost tile in the gallery) opens the config sheet with the Tilings checklist expanded and its search box focused; and each board's hover chrome gains a **✕** that drops the tiling from the run (offered only above the two-board minimum), with removals coalescing into one debounced re-run.
- Forked boards gained a way back to the shared clock: **▶ Run wall from here** on the fork chip makes the fork's current state the wall's shared seed and re-runs every board from it as generation 0 (the fork's live cells pull back through the board's traversal, exactly like a gen-0 paint; multi-state cells collapse to alive since the shared seed is binary; generation numbering restarts by design). The action stays disabled until the fork has actually seeded, since until then there is no state to hand back.
- Retired the speaker view's **seed rail**: painting the shared seed directly at generation 0 (edit mode, either layout) superseded the rail's reparented seed pad and its duplicate "Re-run wall from this seed" button, so speaker view is now just the hero and its thumbnail strip. The seed pad stays in the config sheet for bit-level control.
- The comparison wall's edit mode now **auto-forks a mid-timeline paint**: clicking a board's cell away from generation 0 (where there's no seed bit to edit) forks that board live from its current generation and carries the paint straight over as the fork's first edit, rather than just hinting toward ⏮. The board is not zoomed by the paint — it becomes a compact live tile in place, the same as an explicit ⑂ fork — and a second paint on an already-forked board lands directly on its live session instead of forking again. Standalone with no session falls back to opening the pattern (paint included) into the Lab, same as the explicit fork button's fallback.
- Forks made on the comparison wall now **persist across views**: forking a board (⑂) at generation N leaves the shared clock for its own live, editable session as before, but leaving that board (back to the gallery, or to another board in speaker view) no longer tears it down — it keeps running and renders as a compact live tile among the vector filmstrip boards (just a "live · gen N" badge over its canvas), and re-entering it shows the same session as the hero again rather than forking a second time. Multiple boards can be forked at once, each independent; discarding one leaves the others running. Closing the wall (not just changing focus) still disposes every live fork. The standalone build — where each fork boots its own persist-free Pyodide runtime — caps concurrent forks at 2 with a clear message; the server build, where a fork is just another backend session, is uncapped.
- Added **edit mode** to the comparison wall: a ✎ toggle in the dock arms painting, and clicking any board's cells at generation 0 edits the shared seed directly — the cell pulls back to a seed bit through the board's traversal (the filmstrip payload now carries each board's `seed_order`), generation 0 re-projects onto every board instantly, and a debounced re-run replays the evolution everywhere. Painting one board visibly reshapes all the others. While edit mode is on, clicks paint instead of zooming (the hover ⤢ glyph becomes the one zoom affordance); watch mode is unchanged. A named-shape demo seed (e.g. the featured r-pentomino) converts to an editable bit-string on first paint, with a status cue — the conversion is per-geometry, so the other boards re-project from the bits (a one-time reflow, pinned by `tests/unit/test_seed_pullback.py`). - Replaced the `dodecagonal-square-triangle` runtime with the genuine Schlottmann quasi-periodic square-triangle substitution, removing the family's long-standing periodicity deviation. The previous decorated-3.12.12 Archimedean stand-in was locally 12-fold flavoured but globally periodic; the new runtime is the canonical marked pseudo substitution (inflation `2 + sqrt(3)`, five marked prototiles: red/yellow/blue triangles plus plain/marked squares) with interlocking supertiles deduplicated in the exact `Z[zeta12]` module. The 101 child placements were recovered from the Tilings Encyclopedia substitution-rule figure by exact-geometry image analysis, and every child's marked pose was pinned and verified against the encyclopedia's own 4999-cell literature patch: a two-level supertile decomposition matches with zero colour conflicts, re-expanding the decomposed coarse configuration reproduces the literature patch tile-for-tile (marking colours included), `sigma^2` supertile patches are exactly gap- and overlap-free, and the triangle:square census converges to the canonical `4/sqrt(3)`. The runtime anchors on the blue triangle's interior identity self-slot, so patches converge around a fixed anchor tile, cell ids are stable across depths, and out-of-ball subtrees are pruned (a depth-100 patch of 21k cells builds in about two seconds and passes strict validation). Public vocabulary is unchanged (square kind plus triangle kind with red/yellow/blue chirality tokens); the implementation status moves from `canonical_patch` to `true_substitution`. Manual visual review accepted the rendered quasi-periodic field against the Bielefeld reference on July 2, 2026, so the family was renamed to the accurate "Schlottmann Square-Triangle" catalog label (crediting the substitution's discoverer Martin Schlottmann; the `dodecagonal-square-triangle` geometry id is unchanged) and promoted to the main `Aperiodic` picker group — leaving the `Experimental` group empty for the first time.

- Added the `P-Pentomino` substitution tiling to the main `Aperiodic` group -- the pentomino member of the rep-4 polyomino series alongside the L-tromino `chair` and the `l-tetromino`. The P-pentomino (a 2x2 square block plus one cell) is the *unique* rep-4 pentomino: four half-scale copies exactly tile a double-scale copy, while every other pentomino (L, Y, F, T, N, W, Z) fails rep-4 -- confirmed by exhaustive exact cover of the doubled tile. Geometry is exact on the integer lattice (no irrational coordinates); the four-child dissection was derived in the geometric (polygon) convention so the affine recursion reproduces it exactly, and is verified by area conservation, congruence to the prototile, and a gap-free / overlap-free cover. Unlike the L-tetromino (whose substitution closes over the four-element Klein group), the P-pentomino is chiral, so its substitution closes over the full eight-element dihedral group D4 -- every rotation and reflection appears -- giving richer local adjacency; all eight orientation tokens are present from depth 2 onward, with exact per-depth distributions pinned as independent truth. The shipped representative patch starts from a compact two-supertile 5x2 seed (cell counts 2/8/32/128 at depths 0..3), while the canonical single-supertile proof remains 1/4/16/64. Brings the catalog to 55 tiling families (24 aperiodic).

Geometry is exact on the integer lattice (no irrational coordinates); the rep-4 dissection was found by exhaustive exact cover of the doubled tile and verified by area conservation, congruence to the prototile, and a gap-free / overlap-free cover. The substitution closes over exactly four orientations -- the Klein four-group (identity, 180-degree rotation, and the two diagonal reflections) -- and every tile yields one child of each orientation, so the four orientation tokens are evenly split at every substituted depth. - Added the `Tridecagonal 13-fold` quasicrystal to the main `Aperiodic` group -- the catalog's first 13-fold tiling. It ships the de Bruijn tridecagrid rhomb tiling, the 13-fold analogue of the Penrose (5-fold), heptagonal (7-fold), enneagonal (9-fold), and Socolar (12-fold) rhomb tilings, built by the generalized-dual (multigrid) construction over thirteen line families spaced `2*pi/13` apart. Because 13 is prime, all thirteen families are fully independent -- no antiparallel-family degeneracy and no sub-symmetry concurrences. Every cell is one of the six tridecagonal rhombi with acute angles `k * 180/13` for `k = 1..6` (~13.8, ~27.7, ~41.5, ~55.4, ~69.2, ~83.1 degrees), and the patch is edge-to-edge, gap-free, and overlap-free. Like the other multigrid families this is a bounding-box crop, so the depth-to-cell-count sequence (72/150/317/707 at depths 0..3) is governed by the half-extent rather than a substitution eigenvalue. It is the de Bruijn tridecagrid rhombus tiling, not a marked-prototile substitution. Brings the catalog to 53 tiling families (22 aperiodic).
- Added the `House Pentagonal` tiling to the `Periodic Mixed` group -- the catalog's first simple convex-pentagon monotile. The "house" / home-plate pentagon is a unit square with a symmetric 45-degree roof (interior angles 90 / 90 / 135 / 90 / 135), the simplest Type 1 monohedral convex pentagon in the Reinhardt classification. Upright houses pack in rows sharing their vertical edges; an inverted house fills the downward V between adjacent roofs, and the inverted tops carry the next row shifted by half a cell. That half-cell-per-row shift is a cumulative skew (`lattice_skew_x`), so the descriptor uses a two-tile primitive unit; every coordinate is rational, so unlike the irrational `stein-14-pentagonal` the tiling is genuinely edge-to-edge with exact shared edges (no T-junctions, no tolerance allowlist). Interior vertices are either three houses (90 + 135 + 135) or four houses (90 * 4) meeting. Verified by the descriptor-driven open-boundary 3x3 sample (18 cells, exact kind counts, adjacency, degree histogram, and interior vertex configurations). Brings the catalog to 52 tiling families (28 periodic mixed).

## Dodecagonal Square-Triangle Investigation (Pre-Replacement)

This was a multi-pass effort to recover marked-prototile substitution rules from
the literature-derived source patch. The work was ultimately superseded by the
decorated 3.12.12 Archimedean generator listed above, but the pipeline is
documented here for context.

- Added a first-pass dodecagonal structure miner that reports repeated local shell signatures and bounded square/triangle macro-candidate unions from the literature-derived source patch.
- Added a second-pass dodecagonal supertile miner that grows repeated macro seeds through symmetry-normalized neighbor-slot support, surfacing a stable five-cell square-seeded candidate pattern from the literature-derived source patch.
- Added a third-pass dodecagonal inflation probe that extracts boundary line families from the five-cell seed, searches stable second-ring slot combinations, and surfaces a repeatable ten-cell polygonal closure with an approximate scale-up factor.
- Added a boundary-template inference pass for dodecagonal inflation candidates that canonicalizes repeated larger closures under seed symmetry and reports explicit normalized line-family offsets for the dominant repeated templates.
- Added a line-equation and supertile-decomposition pass for dodecagonal boundary templates that emits explicit normalized line equations and groups repeated interval-signature decomposition components inside the dominant larger templates.
- Added a dodecagonal macro-composition pass that unions repeated decomposition-region signatures and surfaces recurring square macro-cells inside the dominant 8-cell and 10-cell literature-derived templates.
- Added a first recovered-rule pass for dodecagonal templates that promotes repeated macro-composition patterns into explicit substitution-style child rules and checks whether those child rules recur on a slightly deeper shell window of the literature-derived source patch.
- Extracted a reusable planar template-analysis module for polygon context building, subset scoring, boundary canonicalization, line-family inference, slot normalization, and template-component recovery so later tiling miners do not need to duplicate the dodecagonal geometry/template machinery.
- Added a recovered parent-decomposition pass for dodecagonal templates that mixes verified multi-region child rules with recurring singleton square/triangle components, yielding fully covered child inventories for several parent templates and deeper-shell verification counts for each recovered piece.
- Added a canonical parent-rule pass for dodecagonal templates that solves a compact exact cover over recovered composition pieces plus primitive square/triangle components, yielding smaller fully covered child inventories for the strongest parent templates.
- Extended the canonical parent-rule pass with template-local composition mining at a lower support threshold, which reduced the strongest verified 7-cell square-seeded parent to a 7-piece exact cover with three square-valued multi-region children and twelve deeper-shell template matches.
- Folded deeper-window template-local compositions back into the canonical rule candidate pool and gave canonical recovery its own wider template-local decomposition state, which strengthened the strongest verified 7-cell square-seeded parent into a full 7-piece exact cover with four square-valued multi-region children and twelve deeper-shell template matches.
- Added an evidence-ranked parent-rule pass for dodecagonal templates that kept exact-cover recovery from over-optimizing for compactness alone, surfacing fully verified zero-weak-piece covers for the strongest 7-cell square-seeded parent across the deeper verification window.
